## How to Run Locally

### Option 1: One-Click Launch (Windows)
Double-click the **`start_server.bat`** file in this folder. It will launch a local server and automatically open the portfolio in your browser at `http://localhost:3000`.

### Option 2: Direct Browser Open
Double-click **`index.html`** to open it directly in Google Chrome, Microsoft Edge, or any modern browser.

### Option 3: Terminal / Command Prompt
```bash
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your web browser.

## Free 1-Click Deployment (To Share with Recruiters)

### Method 1: GitHub Pages (Recommended)
1. Initialize git and push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of modern portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
2. On GitHub, go to **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your portfolio will be live at `https://<your-username>.github.io/portfolio/` in under 60 seconds!

### Method 2: Vercel or Netlify (Drag-and-Drop)
- Visit [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
- Drag and drop this folder directly into their dashboard to get a free live URL (e.g., `aditya-sisodia.vercel.app`) with SSL enabled.
